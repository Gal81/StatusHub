# Журнал обучения

Короткие записи после каждой завершённой задачи. Журнал нужен, чтобы видеть
свой прогресс и возвращаться к темам, которые остались непонятными.

Новые записи — сверху.

## Шаблон записи

```md
### ГГГГ-ММ-ДД — Задача X.Y. Название

**Что сделал:** одно-два предложения.

**Что понял:** главная мысль своими словами.

**Что осталось непонятным:** вопросы, к которым стоит вернуться
(или «—», если всё ясно).
```
